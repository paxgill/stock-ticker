01
Install Scriptable
Download Scriptable from the App Store (free).

        
02
Create a new script
Open Scriptable → tap + → name it StockTicker.

        
03
Paste the script
Copy the script from the SCRIPT tab and paste it into your new Scriptable script.

        
04
Set your server URL
Update BASE_URL at the top to your server's IP/hostname (e.g. http://192.168.x.x:5000). Both devices must be on the same network, or deploy to a public host.

        
05
Add to home screen
Long-press iOS home screen → tap + → search Scriptable → choose Small or Medium size → select StockTicker.
